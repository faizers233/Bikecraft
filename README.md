## 📖 Overview

**Bikecraft** is a high-end bicycle shop project developed as part of the **Origamid HTML and CSS for Beginners** course. The main goal was to move beyond the basics and master the art of creating pixel-perfect, accessible, and responsive layouts.

This project represents the bridge between being a student and becoming a professional developer, where semantic structure meets advanced CSS layout techniques.

---

## 🎯 Learning Milestones

During the development of this project, I gained deep expertise in:

* **Semantic HTML5:** Using the correct tags (`<article>`, `<aside>`, `<nav>`, `<header>`) to ensure the website is SEO-friendly and accessible.
* **CSS Grid & Flexbox:** Implementing complex layouts. **Flexbox** was used for components and one-dimensional alignments, while **CSS Grid** was used for the main page structure and galleries.
* **Typography & Colors:** Working with external fonts (Google Fonts) and a strict color palette to maintain brand consistency.
* **Responsive Web Design (RWD):** Developing with a mobile-first mindset and using media queries to ensure a seamless experience across all device sizes.
* **UI/UX Fundamentals:** Focusing on hover states, transitions, and user flow to create a premium feel.
